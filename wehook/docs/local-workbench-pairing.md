## 已实现

- 运营员 `POST /v1/admin/local-pairings`：指定 tenantId，installationIds 为 null 时授权客户名下小店的发现；数组时限定到指定店铺。仅相同客户的店铺可纳入。
- 客户管理员 `POST /v1/account/local-pairings`：tenantId 固定取登录会话，忽略请求中的客户 ID。
- 本地端 `POST /v1/local-shop/pair`：提交 code/name，一次性兑换专用连接 token；配对码五分钟到期，重发使该客户以前未使用的码失效。兑换必须原子完成，数据库只存摘要。
- 本地端 `GET /v1/local-shop/discovery`：Bearer 专用连接 token，只返回获授权客户的店铺安装 ID、名称、AppID 和状态，不返回平台密钥。它不等于占用店铺或启用真实收发。
- 运营员或客户管理员 `POST /v1/{admin|account}/local-clients/:id/revoke`：撤销连接凭证；客户管理员只能撤销自己的连接。
- 连接凭证与原积分设备 token 分离，不继承扣费权限；旧设备 token 不能用于聊天发现。
- ShopGatewayAdapter 将已入库的云端消息转换为 Rag 标准消息。绑定取服务端可信配置，按客户/店铺/OpenID 解析回复目标，不拿本地会话 UUID 当云端 UUID。稳定 commandId 交给已有幂等发送层。
- 图片经远端 Bearer 鉴权出口及本地账号/会话权限代理读取；校验类型与大小，地址不带凭证，失败可重试。本机实际图片代理读取已返回 JPEG 200。
- 客户来源、UnionID、卡片字段随 Rag 的 content JSON 保留；不跨店合并，不伪造昵称头像。远端备注入口已移除，旧编辑接口返回 410，新配对不继承远端备注；本地聊天头部提供备注并仅修改本地显示名称。
- 事件 ID 按店铺/平台消息编号稳定派生；已有事件重放使用原 payload，避免备注变动导致事件 ID 冲突。
- Rag 入站检查账号映射的渠道和店铺 ID。小店后处理默认 allowAutoReply=false，并清理旧 AI 队列；现有非小店行为保持不变。
