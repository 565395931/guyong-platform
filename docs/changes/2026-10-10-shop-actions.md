# 微信小店断开连接与店铺资料删除

日期：2026-10-10。用户要求新增功能，暂时不执行远端删除；本轮没有实际删除或断开任何现有店铺。

## 操作语义

- 远端店铺列表新增清楚可见的“断开连接”，仅解除所选店铺的本地绑定；两端聊天、远端登记和其他店铺保留。未连接时禁用。
- 远端“删除店铺”使用独立危险确认弹窗，要求输入完整店铺名称。删除登记、凭据、会话、消息、旧客户资料、发送/投递记录，解除关联绑定并失效相关待用配对码；不删除租户、其他店铺或本地已有资料，不切换微信小店客服模式。
- 本地账号管理中的“删除店铺”先核对数据库记录数，再要求输入完整店铺名称。清理所选账号及其会话、消息、备注、身份关联，以及按账号/会话/订单/报价关系归属的数据库资料；不是仅把列表隐藏或设为停用。
- 本地删除先解除该店远端配对并等待在途入站完成；在途发送时拒绝删除。数据库采用事务、子记录先删除、账号最后删除，失败回滚。连接变更互斥，失败保留可重试状态，其他店铺运行时重新恢复。
- 共享客户/系统用户/商品主档不随店铺删除。保留加密恢复备份及安全审计；没有页面一键撤销，也不承诺删除备份或共享附件实体文件。
- 本地删除保留远端原始消息，重新配对会同步历史，这是正常重放。若只想重测连接，无需使用远端删除。

## 代码入口

- 本地删除领域：Rag/rag-server/src/modules/cloud-gateway/shopAccountDeletion.js，路由 channelAccounts.js；GET /:id/deletion-preview 与带 confirmName 的 DELETE /:id，沿用 admin/supervisor 授权。
- 本地界面：AccountManage.vue / ShopDeleteDialog.vue；成功后刷新账号、清理该账号会话缓存与统计。
- 单店解绑：LocalShopConnection.detachAccount / LocalWorkbenchPairing.detach；POST /v1/local-shop/detach 为机器 Bearer 接口，支持安全重试及租户隔离。
- 远端：POST /v1/admin/shops/:id/disconnect 与 /delete，沿用 operator 与同源校验；WechatShopService.remove 和 LocalShopTransport.purgeShop 清理领域记录及持久投递数据。
- FileEventStore 清理后重排剩余序号与游标，避免追加时序号碰撞；删除后在途 AI 建议/回复不能重新创建已删除的会话资料。
- 界面沿用现有设计规范、共享弹窗和 Element Plus；危险操作与普通动作分开，取消优先聚焦，提交防重和关闭保护，错误内联保留输入。
