## 5. 稳定性与可见性

- **两轮一致性**：连续两次全树读取（间隔 2s），29/29 条文本完全一致。
- **后台可读**：捕捉时前台窗口是 ZCode（`GetForegroundWindow` 取证），千帆未被置前。
- **视图切换跟随**：09:36 捕捉视图一（97 节点）、09:38 捕捉视图二（307 节点），
  同一渲染宿主 hwnd=656814，无需重新定位；捕捉产物按视图名另存副本，不被覆盖。
- **隐藏不可读**：隐藏的 `eva` 副窗口渲染宿主只读到 1 节点 / 0 文本（与飞鸽一致）。
- **冷启动预热**：飞鸽实测 Chromium 首次启用无障碍树需约 15s 预热；千帆未复测
  （下次客户端冷启动后应先连续两次读节点数一致再采信）。

## 9. 附：订单采集（点击导航，非只读，2026-10-13 追加）

在只读捕捉之外，打通了「定时点进订单页 → 抓取 → 点回客服页」的元素级自动化
（`qianfan_orders.py`，节点内定时任务调用）。关键实测：

- **点击方式**：优先 `LegacyIAccessible.DoDefaultAction`，失败退回 `InvokePattern`；
  **不使用屏幕坐标、不模拟鼠标**。早期用真实鼠标坐标点击可以工作，但窗口一移动
  坐标即失效（实测窗口从 x=245 移到 x=1374 直接翻车），已弃用。
- **遮挡/后台状态会禁用 UIA 动作**：千帆窗口被压到后台时，Chromium 把渲染宿主缩进
  隐藏容器 `Chrome_WidgetWin_0`，所有动作返回 ELEMENTNOTAVAILABLE（读取不受影响）；
  提窗到前台约 1~2 秒后宿主搬回可见主窗口，动作恢复。采集流程据此设计为
  「直接尝试 → 失败则提窗 → 等恢复 → 重试」。
- **视图判断用内容标记**（'当前会话' / '订单管理'），不用文档名——客户端故障时
  DocumentControl 名会固定显示 '你访问的页面不见了'。
- **查询状态是粘性的**：一次空查询（搜索类型未选/日期为空）会让列表长期停在
  "查询结果为空"，重进模块也不恢复；采集前固定执行「重置条件 → 搜索」拉回默认集。
- **订单表格字段**（11 列全可读）：订单号 / 状态 / 用户名 / 用户ID / 手机号 /
  商家名称 / 发货仓 / 收货地址 / 运单号 / 创建时间 / 操作列表（备注、联系买家）。
  实测一轮采到 **18 条真实订单**（单页 20 条规格内；分页场景未覆盖，总数超一页时
  会记录告警）。
- **失败安全**：`try/finally` 保证无论采集成败都点回客服页；前台窗口在结束后还原。

节点侧接入：`bridge_node.py` 注册双适配器（`doudian.feige` + `xiaohongshu.qianfan`），
按 `QIANFAN_ORDERS_ENABLED` / `QIANFAN_ORDERS_AT=HH:MM` 每日定时子进程调用采集器，
同日不重复触发。建号检测探针 `detect.py` 输出契约与飞鸽一致（单行 JSON），
机器指纹与飞鸽算法相同（实测两平台指纹一致，账号绑定同一节点）。

## 10. 附：订单入库（2026-10-13 追加）

采集到的订单经桌面桥接上报入库（`commerce.orders.scraped` → `orders` 表，按订单号幂等）：

- 节点：采集成功 → 读 latest JSON → WS 上报 → `event.ack` 回执（`新增 N 条、更新 M 条`）记入节点日志；
- 服务端：`scrapedOrderIngestService` 做字段映射与幂等 upsert（`INSERT ... ON DUPLICATE KEY UPDATE`），
  新订单写 `order_events` 轨迹；人工补录可跑 `rag-server/scripts/ingest-scraped-orders.js`；
- 状态映射（千帆 → 平台词表）：待付款→draft、待发货→paid、已发货/待收货→domestic_shipping、
  **已签收→delivered**、**已完成/已关闭→closed**、取消发货/已取消→cancelled、退款/售后→after_sales；
  未知状态回落 confirmed 并记警告，原文保留在 `raw_payload`。
- 实测：18 条真实订单入库（delivered 2 / closed 12 / cancelled 4），幂等复跑只更新不新增；
  列表页不含商品明细与金额（`order_items`/金额为空），运单号等存 `raw_payload`（待详情页采集补齐）。
