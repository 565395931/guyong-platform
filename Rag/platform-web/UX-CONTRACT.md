# 工作台会话交互契约

沿用 DESIGN.md、现有 Element Plus 与会话状态仓库，不新增视觉系统。

## 范围与状态

- 渠道与账号切换立即清空旧会话；过期请求不得恢复旧选择；草稿随会话隔离。
- 归档会话禁止发送，不提供释放/转 AI/归档动作，生命周期操作仅为复活；成功后进入待人工。
- 本地备注使用现有授权更新接口，稳定用户 ID 不变；只有保存成功才更新展示。清空回退用户 ID，不写入远端。
- 备注弹窗自动聚焦；请求中防止重复提交；失败保留草稿并可重试；取消未保存修改需确认。
- 店铺删除先读取受授权的数据库范围预览，失败可重新核对；输入完整店铺名称确认，提交中禁重复/关闭，错误内联并保留输入。成功后清除该账号的当前会话和列表缓存、刷新账号列表与统计。
- 删除清理所选本地渠道账号及按账号、会话、订单/报价/身份关系归属的数据库行；解除该店远端配对，保留其他店铺、共享客户主档及远端登记/原始消息。重新配对会重放远端历史；加密备份不等于页面可撤销。

## 责任与验证

- 会话仓库负责选择与列表展示，channelScope 负责渠道/账号匹配，conversationActions 统一生命周期判断。
- ChatWindow/ConversationItem 复用动作规则；CustomerRemarkDialog 负责备注保存和取消保护。
- 2026-10-10 店铺操作：178 项前端测试及构建通过；两端严格 UI 静态审计通过。浏览器登录态不可用，未宣称删除弹窗完整点击或视觉验收完成。详见根 docs/changes/2026-10-10-shop-actions.md。

## 大模型余额与失败提醒（2026-10-10）

- 服务商余额由远端返回，页面每分钟校准；未知余额不视为零。自有 Key 不查询余额，显示“—”。
- 余额 <10 元时配置页面深红提示；全局每小时最多一次确认弹窗，确认关闭且刷新不重复。
- 外部 Key 连续三次回复失败提示一次；成功复位，配置身份隔离。
- 使用既有 Element Plus 弹窗和表单。两端测试、静态审计与实际浏览器验证见根 docs/changes/2026-10-10-ai-balance.md。

## 模型配置与测试
连接保存为单个配置，Key输入留空保留已保存凭据；首次必须填写。清空连接需确认，不删除百炼。测试页只读已保存配置，未配置禁发；请求中禁重复提交，错误保留输入；图片验证限制350KB。实际浏览器结果见根docs/changes/2026-10-10-model-config-key.md。

模型测试：切换测试模型不修改正式客服模型，切换即开始新会话。清空记录清除history、错误、失败气泡、草稿、图片、结果；请求中禁清空，完成后可重新开始。每次发送首条system使用保存提示词，历史只携带配置条数。

模型测试的回复决策使用服务端内置协议，页面只显示客户文本及正常回复/追问/转人工状态。转人工标记在测试页不执行真实客户操作，清空不移除业务提示词。

百炼检索：API Key单独加密保存，留空保留旧Key；API模式需要Workspace/Index ID。测试只用已保存配置，失败保留问题并清除陈旧资料。旧AccessKey上传管理折叠保留，切换SDK模式不删除API凭据。模型联合测试开关在API配置有效后开放，切换会清空对话。

配置回显：保存后及重新打开页面，模型地址、模型、上下文、业务提示词、百炼ID继续显示；已保存Key在输入框显示掩码与尾号。原样掩码不得作为新密钥提交；覆盖填写用于更换。快速填写只提供远端服务和DeepSeek两个模板。

模型与百炼标题右侧使用Element Plus独立开关，立即保存，提交中禁止重复操作，失败恢复原值并提示重试。关闭不清空配置；模型关闭禁自动回复和测试，百炼关闭不检索，允许仅模型回答。测试页联合检索默认遵循已开启且完整的知识库配置。

默认提示词模板：模型保存按钮旁提供可编辑模板弹窗，标题提示非技术人员不要改动。模板编辑独立保存；恢复默认填回内置内容，保存后生效。取消有修改时确认放弃，失败保留草稿，请求中禁止关闭和重复提交。模板来自后台，业务提示词位于模板前，JSON协议后置。一次请求一个system，历史只保留客户/客服消息，当前知识库资料放在本轮客户消息中，不存入测试历史。

转人工与自动回复：首次转入待人工按通用设置发送提示，待人工停止AI接待。认领或人工提交发送时使排队及生成中的回复作废，发送前复查状态与会话版本；转回AI恢复。归档时停止发送，新客户入站重新打开后恢复按当前开关接待。消息审核页面、菜单、计数和后台流程已移除，JSON解析与会话权限继续生效。

AI会话允许绑定该平台账号的普通客服监控；待人工会话在Admin处等待至少10秒再自动分配。普通客服待人工仅显示分配给自己坐席的客户；分配保留待人工状态，人工发送后接管。平台消息公共页面不展示中转或桌面接入说明条。

聊天附件：复用ChatInput/Element Plus上传与媒体库。微信小店允许5MB内PNG/JPG，选择、粘贴、拖入先上传并预览；上传中禁发送和重复上传。图片和文字分开发送，文字草稿保留。提交成功清除附件；明确失败保留附件，结果不确定清除附件避免盲目重发。未确认状态不能显示已发送；失败原因和结果待确认持续显示，刷新后仍可读取。只有明确failed可重试，重试媒体保留mediaFileId。

## 可配置渠道提示词与发送失败详情（2026-10-10）

AI配置默认模板旁的渠道提示词入口复用Element Plus弹窗、选择器、文本域和通知。渠道列表来自既有渠道定义API，各渠道默认空字符串；切换渠道保留当前编辑草稿，独立保存整份渠道配置，取消有修改时确认放弃，提交中禁止关闭/重复提交，失败保留草稿和弹窗。提示词顺序严格为系统提示词→当前渠道提示词→默认模板，无写死渠道附加规则。测试页选择渠道后清空历史并应用同一配置。

发送失败图标为可聚焦按钮，点击/Enter打开失败详情，不直接重发；Escape关闭并恢复焦点。10190010显示规定错误说明，仅关闭，不提供原样重发按钮。其他明确失败可在详情中明确选择重试，结果不确定仍禁止重复发送；失败原因从持久化回执读取。禁止把被风控拒绝的内容自动转换为图片规避检查。


## Admin 与普通客服（2026-10-12）

业务来源：[团队接待规则](../../docs/changes/2026-10-12-admin-team-routing.md)。

- 角色入口只保留 Admin 与普通客服；账号管理、AI 配置、平台连接操作受前后端共同保护。
- 普通客服初始页为“我的会话”；状态按钮位于 AppHeader，单击按在线→忙碌→离线循环，分别绿色/黄色/灰色。重连保留手动状态；同平台多客服时离线不自动分配，唯一客服无论离线仍分配。
- Admin 账号表显示普通客服接待状态、人数；新增账号由Admin在平台账号页面明确增减客服绑定，账号启用状态与接待状态分别展示。
- QuickReplyPanel 无需客户选择；所有人可新增/编辑/移除自己的话术，只有 Admin 可明确选择更新公共库。恢复需确认，保留个人新增话术；所有操作使用既有 Element Plus 按钮、选择器、弹窗和通知。
- 状态轮询禁止重叠，失败可重试；个人话术提交禁止重复，失败保留草稿。列表分页读取全部可见话术；图标操作有可访问名称及键盘行为。

## 平台客服与会话归属（2026-10-12）

- 所有平台账号页面提供配置客服账号，只新增/删除已有普通客服绑定；失败可重试，提交中禁重复，未保存离开需确认。权限变更立即刷新实时订阅和可见会话。
- Admin和客服均显示待人工、AI、我的、归档；渠道由导航选择，取消会话列表渠道下拉框及长期收藏动作。长期旧记录仍在我的。
- 客服一旦提交人工回复，该客户持久归属我的；AI/人工切换不取消归属，归档从活跃我的移入归档。今日接待按已回复的独立客户计数，重复回复不重复增加，每天北京时间19:00重置。
- 通用设置为系统设置首项，只有Admin可修改转人工提示开关及内容；失败保留草稿，未保存离开确认。
- 人工发送先使AI版本过期，生成中的模型调用消费保留；尚未发送的结果及迟到失败回执不能重新打开归档或改写新状态。平台已经接收的消息无法撤回。
- 状态closed或conv_status archived均按归档展示；存量冲突在保留修复前状态后统一为归档，不在待人工显示复活。
