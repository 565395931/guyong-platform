# 产品与报价操作手册

本模块把 MySQL 中的已发布目录作为 AI 正式报价的唯一数据来源。Markdown 和 Excel 只用于导入，不是运行时价格表；导入后不要继续通过修改 Markdown 调价。

## 权限

- `admin`、`supervisor`：新建草稿、导入、编辑和发布。
- `agent`：查看目录并使用报价校验，不能修改数据或发布版本。
- 已发布版本和历史版本只读，任何调整都必须在草稿中完成。

## 新建草稿

1. 打开“产品与报价”。
2. 点击“新建草稿”。
3. 在版本选择器中确认当前版本状态为“草稿”。

草稿修改不会影响线上 AI 回复。同一时间可以查看历史版本，但只有草稿可编辑。

## 导入并检查警告

1. 点击“导入文件”，选择 `.md`、`.xlsx` 或 `.xls` 文件，单个文件不超过 10 MB。
2. 点击“解析预览”，检查产品、SKU、价格规则、运费规则数量及全部警告。
3. 只有预览状态可接受时，“写入新草稿”才可用。
4. 确认后，系统会创建一个新的草稿版本并写入数据。

Excel 可使用 `Products`、`SKUs`、`Prices`、`Freight` 工作表。相同内容的文件通过哈希识别；已经提交过的重复文件不能再次写入。

## 编辑产品与价格

- “产品与 SKU”：维护产品编码、名称、说明、规格、包装、重量和覆盖面积。
- “价格规则”：为具体 SKU 维护客户类型、数量区间、单位、币种、单价和有效期。
- “运费规则”：按国家或区域、DDU/DDP/其他交付方式维护首重、续重和费用；无法固定运费时启用“需要人工确认”。

编码统一保存为大写。数量区间不得重叠，价格必须大于 0。正式价格只在前端和数据库中维护，不要在导入后的 Markdown 中修改。

## 报价校验

1. 打开“报价校验”。
2. 输入 SKU、数量、客户类型和币种；需要运费时再输入国家或区域、交付方式和重量。
3. 点击“查询正式报价”。
4. 核对状态、目录版本、价格规则 ID、运费规则 ID、商品金额、运费和总金额。

报价校验只读取当前已发布版本。没有精确匹配规则时，结果必须是 `manual_confirmation`，不得根据聊天记录或普通文档猜价格。

## 发布

1. 在草稿中完成产品、SKU、价格和运费检查。
2. 使用“报价校验”验证代表性的零售、批发、数量阶梯和国家/区域组合。
3. 由 `admin` 或 `supervisor` 点击“发布版本”并确认。

发布后，该版本立即成为 AI 精确报价的数据源，之前的已发布版本自动转为历史版本。生产环境发布前必须由业务负责人复核。

## 回滚

不要修改已发布行。需要回滚时，从目标历史版本克隆或重新导入到一个新草稿，在“报价校验”中验证后再发布该草稿。发布动作会保留完整版本和操作审计记录。

当前界面尚未提供一键克隆历史版本时，可重新导入对应的已审核源文件，或由管理员通过受控数据迁移创建草稿；不得直接执行 SQL 修改已发布数据。

## 故障处理

- 导入被拒绝：检查文件扩展名、10 MB 限制、工作表名称、必填列和预览警告。
- 提示重复文件：确认该文件已经提交过，切换到对应版本检查，不要重复导入。
- 报价返回 `manual_confirmation`：检查是否存在已发布版本，以及 SKU、币种、客户类型、数量区间、有效期、地区和交付方式是否精确匹配。
- 页面显示 401：重新登录；仍失败时检查 `JWT_SECRET` 与登录服务是否使用同一配置。
- 页面显示 403：当前账号只有查看权限，请由主管或管理员操作。
- 页面无法读取数据：检查 `rag-server`、MySQL 和反向代理 `/api` 是否可用，查看服务日志中的目录表初始化结果。
