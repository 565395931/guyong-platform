# 取消AI发送失败截图补发

用户明确取消截图功能，发送失败直接转待人工池。AI即时失败、远端异步最终失败、发送unknown均只转人工，不渲染、不补发。历史未处理的AI图片失败回执同样转人工，不生成新图。人工已认领时不覆盖其会话状态；重复回执仍去重。

删除replyImage.js和playwright-core依赖。保留手动图片发送、历史消息及媒体文件，没有删除客户记录。保留发送前入库、真实状态回执与重启恢复。无需远端或前端修改。

后台626项测试通过：直接失败转人工、异步失败转人工、unknown不重复发、人工认领保护、正常发送不转池、人工消息不触发AI转池、旧AI图片失败无补发。无活动AI任务时停止旧后台，修正后重启；小店连接验证在线。没有真实客户测试消息发送。
