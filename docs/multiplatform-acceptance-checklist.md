## 远端服务器与本地工作台怎么接起来

操作顺序：**远端准备测试客户与店铺 → 商家管理员核对接入 → 远端生成配对码 → 本地 Admin 连接远端 → 本地 Admin 创建并绑定客服 → 客服与买家验证收发。** 远端运营管理员不等于处理日常咨询的普通客服。

## 测试人员先看这里

**管理员负责准备环境和分配权限，客服账号负责测试日常工作。两种账号都要测，不能只用 Admin 测完全部功能。** Admin 的权限更大，只用它测试，可能发现不了普通客服看不到消息、无法接管或能越权访问其他店铺的问题。

请按这个顺序执行：

1. **管理员准备**：先按最前面的账号准备表备齐登录条件；微信小店先按 R01–R10 完成远端配置和本地配对，再按 T01–T03 创建或核对“客服 A”和“客服 B”及店铺权限。纯桌面平台不需要照做微信小店的远端接入流程。
2. **客服测试**：退出 Admin，分别登录客服 A、客服 B，完成 T04–T10，再测各个平台的会话和人工收发。
3. **买家配合**：用平台上的测试买家账号给测试店铺发消息，核对工作台显示和回复。买家账号不是本系统的客服账号。
4. **技术人员协助**：标有“技术协助”的项目交给部署或开发人员操作，测试人员配合观察。普通测试人员不用自行改配置、停数据库或构造网络报文。
5. **最后测试 AI**：人工收发和权限隔离通过后，再按 I 组验收自动回复；当前缺少实现或设备的项目填写“阻塞”。

结果填写规则：符合该行全部“通过标准”后才勾选；不符合写“失败”；缺少客户端、账号、第二家店铺或功能实现时写“阻塞”，不要当作通过。失败和阻塞都填写文末的结果记录。
